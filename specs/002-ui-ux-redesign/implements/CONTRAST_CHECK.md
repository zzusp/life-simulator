# 对比度校验报告（AA 级别）

## 概述

根据 WCAG 2.1 AA 级别要求，本文档记录全站关键文本与背景的对比度校验结果。

## 校验标准

- **普通文本（< 18pt 或 < 14pt 加粗）**: 对比度 ≥ 4.5:1
- **大文本（≥ 18pt 或 ≥ 14pt 加粗）**: 对比度 ≥ 3:1
- **非文本内容（图标、按钮边框等）**: 对比度 ≥ 3:1

## 主要颜色配置

### 基础色板
- **Primary**: `hsl(221.2, 83.2%, 53.3%)` - #3B82F6 (蓝色)
- **背景**: `hsl(0, 0%, 100%)` - #FFFFFF (白色)
- **前景**: `hsl(222.2, 84%, 4.9%)` - #0C0A1F (深灰)
- **灰色-900**: #111827
- **灰色-700**: #374151
- **灰色-600**: #4B5563
- **灰色-500**: #6B7280
- **灰色-400**: #9CA3AF

### 分数色阶
- **绿色-600** (`text-green-600`): #059669 (80-100分)
- **黄色-600** (`text-yellow-600`): #D97706 (60-79分)
- **橙色-600** (`text-orange-600`): #EA580C (40-59分)
- **红色-600** (`text-red-600`): #DC2626 (0-39分)

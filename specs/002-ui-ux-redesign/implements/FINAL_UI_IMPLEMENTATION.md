## 技术实现

### Tailwind类使用
```tsx
// 标准卡片
"bg-white rounded-2xl p-6 border-3 border-gray-800 shadow-md"

// 信息卡片（浅蓝）
"bg-blue-100 rounded-2xl p-6 border-3 border-blue-400 shadow-md"

// 主按钮
"bg-teal-500 hover:bg-teal-600 text-white border-3 border-teal-700 rounded-xl"

// 选择卡片
"bg-white rounded-2xl p-6 border-3 border-gray-800 hover:shadow-lg hover:scale-[1.02]"
```

### 交互效果
- 悬停: `hover:shadow-lg hover:scale-[1.02]`
- 选中: `border-teal-500 bg-teal-50`
- 禁用: `opacity-50 cursor-not-allowed`
- 过渡: `transition-all`

## 背景

## 当前内容安全策略

目前系统通过以下方式确保内容安全：

1. **AI提示词控制**
   - 在提示词中明确要求生成安全、积极的内容
   - 禁止生成暴力、色情等不当内容
   - 要求内容符合游戏主题

2. **人工监控**
   - 定期检查生成的场景内容
   - 收集用户反馈
   - 必要时调整提示词策略

## 未来实现方案（可选）

如果需要重新实现内容审核功能，可以考虑以下方案：

### 方案一：简单关键词过滤

**优点**：
- 实现简单
- 无额外API成本
- 响应快速

**实现要点**：
```typescript
// 示例代码
const sensitiveWords = ['暴力', '血腥', '色情', ...];

function checkContent(content: string): boolean {
  return !sensitiveWords.some(word => content.includes(word));
}
```

### 方案二：第三方内容审核API

**可选服务**：
- OpenAI Moderation API
- 阿里云内容安全
- 腾讯云天御
- 百度内容审核

**优点**：
- 专业准确
- 持续更新
- 多维度检测

**缺点**：
- 额外成本
- 增加响应延迟
- 需要处理API失败情况

### 方案三：混合方案

结合关键词过滤和API审核：
1. 先进行快速的关键词预检
2. 可疑内容再调用API详细审核
3. 平衡成本和准确性

## 决策记录

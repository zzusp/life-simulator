## 核心功能特性

### 🎯 游戏核心循环
1. **选择人生类型** → 开始新游戏
2. **AI生成场景** → 显示场景和选项
3. **玩家做出选择** → 计算分数影响
4. **生成下一场景** → 继续游戏或结束

### 🧠 AI智能特性
- **动态场景生成**: 基于人生类型和当前状态
- **智能选择生成**: 符合游戏主题的选择选项
- **推理分析**: 解释选择的影响和理由
- **内容审核**: 确保内容安全和质量

### 📊 游戏系统
- **分数系统**: 0-100分，影响游戏结局
- **选择记录**: 完整的游戏选择历史
- **成就系统**: 支持成就解锁和跟踪
- **状态持久化**: 游戏状态自动保存

### 🔒 安全特性
- **内容审核**: 多层次内容安全检查
- **数据保护**: 匿名游戏，无个人数据收集
- **错误处理**: 完善的错误处理和降级策略
- **类型安全**: 全栈TypeScript类型检查
